# Cleanwheels Thumbnail Kit

Claude writes the prompt. You paste it into ChatGPT and attach the images.

## Set up the Claude Project (one time)
1. In Claude, create a Project named "Cleanwheels Thumbnails".
2. Paste `PROJECT_INSTRUCTIONS.md` into the project's custom instructions.
3. Add `brand-guide.md`, `styles.md` and `logo/cleanwheels-logo.png` to project knowledge.

## Daily use
1. Message the project: `Fortuner` (or `Fortuner + photo attached` if you have a detailed-car photo; the photo is optional, and you can drop it into Claude to check it matches).
2. Claude replies with the prompt plus what to attach.
3. Open ChatGPT in image mode, attach the logo (and your photo), paste the prompt.
4. Ask for tweaks in either place. If the logo comes out wrong, say "use the attached logo exactly, do not redraw it".

## First step now
Try the 5 sample prompts in `styles.md`, tell me which style you like, and I'll lock it in.

## Skill version
`skill/cleanwheels-thumbnail-prompts.zip` is the same project packaged as a Claude skill (Settings > Capabilities > Skills > Upload). Use it instead of, or alongside, the Project.
